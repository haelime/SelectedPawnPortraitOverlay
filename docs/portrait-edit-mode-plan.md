# 초상화 편집 모드 — 2단계 구현 브리프

작성: 2026-10-17. 1단계(실측 기반 자동 맞춤, `PortraitAdjustment` 자리)가 끝난 뒤 이어서 구현한다.

## 목적

설정 메뉴의 슬라이더 대신, 패널 위에서 드래그·휠로 초상화 구도를 직접 맞춘다.
사용자의 조정은 자동 맞춤 위에 얹히는 "차이값"으로 저장되어, 옷이 바뀌거나 자동 맞춤이 개선되어도 의도가 유지된다.

## 확정된 결정

| 항목 | 결정 |
|---|---|
| 도구 막대 | 패널에 마우스를 올렸을 때만 표시. 설정에서 끌 수 있음(`ShowHoverToolbar`, 기본 켬) |
| 편집 모드 기본 범위 | "이 폰" |
| 폰별 보정 저장 위치 | 세이브 파일(GameComponent) |
| 프리셋 이름 | 전신 · 상반신 · 얼굴 |
| 기존 사용자 | 구도는 바뀌지 않음. 도구 막대만 새로 보임. 첫 표시 때 한 번 안내 |

## 데이터 모델

```
PortraitAdjustment { float ZoomMultiplier = 1; float OffsetX = 0; float OffsetZ = 0; }
```
- 항등값(1, 0, 0)이면 "보정 없음"으로 취급하고 저장하지 않는다.
- 적용 순서: 전체 설정 → 종족 보정 → 폰 보정. 각 단계는 아래 단계 결과에 대한 차이값(줌은 곱, 이동은 합).
- 최종 구도 = `PortraitFraming.Compute(전체 줌, 얼굴 강조, 자동 맞춤 배율, 머리 높이)` 에 종족 보정, 폰 보정을 차례로 적용.

저장 위치
- 전체: 기존 `CameraZoom`, `FaceEmphasis` 등(모드 설정 파일).
- 종족: 모드 설정 파일. 기존 `RaceZoomOverrides: Dictionary<string, float>` 를 `Dictionary<string, PortraitAdjustment>` 로 확장. 아직 출시 전이므로 필드 이름·형식을 바꿔도 된다.
- 폰: 세이브 파일. `SelectedPawnPortraitOverlayComponent.ExposeData` 에 `Dictionary<int, PortraitAdjustment>` (키 = `pawn.thingIDNumber`). 폰이 파괴·소멸되면 항목은 그대로 두고 설정 화면에서 "없는 폰"으로 정리할 수 있게 한다. 모드를 제거해도 세이브에는 무시되는 데이터만 남는다.
- 자르기(cutoff)와 패널 크기·위치는 전체 설정에만 둔다(범위 칩의 영향을 받지 않음).

## 패널 UI

### 평소
- 지금과 같다. 클릭·휠은 맵으로 통과한다(`AllowDragging` 이 꺼져 있으면 지금처럼 입력을 잡지 않음).

### 마우스를 올렸을 때 (`ShowHoverToolbar` 가 켜진 경우)
- 패널 아래쪽에 반투명 도구 막대가 나타난다. 약 0.15초 페이드. 마우스가 벗어나면 사라진다.
- 버튼 4개(아이콘 + 툴팁): 편집(✎) · 자동 맞춤 · 이 폰 고정 · 설정.
  - 자동 맞춤: 현재 폰의 폰별 보정을 지운다. 툴팁 "이 폰의 보정을 지우고 자동 맞춤으로 되돌립니다". 폰별 보정이 없으면 비활성 표시.
  - 이 폰 고정: 선택을 바꿔도 이 폰을 계속 표시(`KeepLastPortrait` 와 별개의 명시적 고정). 다시 누르면 해제.
  - 설정: 모드 설정 창을 연다.
- 도구 막대 위에서는 클릭이 맵으로 통과하지 않는다. 그 외 영역은 평소와 같다.

### 편집 모드
들어가기: 도구 막대의 ✎, 또는 설정 가능한 단축키(기본 없음, RimWorld `KeyBindingDef` 로 등록).
나가기: Esc, ✎ 다시 클릭, 다른 폰 선택, 패널이 사라지는 상황. 변경은 즉시 저장된다.

표시
- 패널 테두리를 강조색으로 그린다.
- 상단 바: 범위 칩 `[이 폰] [종족: {종족명}] [전체]`. 선택된 칩은 채움. 해당 범위에 저장된 보정이 있으면 칩에 점 표시. 칩에 마우스를 올리면 × 가 나타나고, 누르면 그 범위의 보정만 지운다.
- 상단·하단 자르기 손잡이(현재 `TopCutoff`/`BottomCutoff` 위치), 오른쪽 아래 모서리 크기 손잡이.
- 하단: 프리셋 버튼 `전신 · 상반신 · 얼굴`.
- 패널 바로 옆에 작은 수치 읽기 `줌 1.20× · X +0.05 · Z +0.15` (현재 범위의 차이값). 더블클릭하면 숫자 입력.

입력 (모두 편집 모드에서만, 패널 위에서만 소비. `Event.current.Use()` 로 맵에 전달되지 않게)
| 입력 | 동작 |
|---|---|
| 초상화 영역 드래그 | OffsetX/OffsetZ 변경. 화면 픽셀 → 월드 단위 변환은 현재 줌을 사용 |
| 휠 | ZoomMultiplier × 1.05^틱. Shift+휠은 1.01^틱 |
| 상단·하단 손잡이 드래그 | TopCutoff/BottomCutoff (전체 설정) |
| 모서리 손잡이 드래그 | PanelWidth/PanelHeight (전체 설정) |
| 제목 줄 드래그 | 패널 이동(기존 동작) |
| 프리셋 클릭 | 현재 범위의 보정을 프리셋 값으로 덮어씀 |
| 우클릭 | FloatMenu: 이 폰 보정 삭제 / 이 종족 보정 삭제 / 둘 다 삭제 / 전체 설정 초기화(확인 대화) / 설정 열기 |
| Ctrl+Z | 편집 모드 안에서 마지막 변경 되돌리기(삭제 포함). 게임 세션 동안만 유지되는 스택, 최대 50 |

프리셋 정의 (1단계의 실측 상자 `bounds` 를 사용)
- 전신: 측정 상자 전체가 들어가게. 자동 맞춤 결과와 같으므로 보정 = 항등.
- 상반신: 측정 상자의 위쪽 60%를 세로로 채움. 인간형은 머리 높이(`BaseHeadOffsetAt`) 를 포함하도록 보정.
- 얼굴: 인간형은 머리 중심을 화면 중앙에서 약간 위에 두고 머리 높이의 약 2.5배가 세로에 들어가게. 비인간형은 측정 상자의 위쪽 35%.
- 세 프리셋 모두 현재 패널 비율(`aspect`)을 고려해 가로가 잘리지 않게 한다.

## 제거·초기화 경로

세 군데에서 같은 일을 할 수 있어야 한다.
1. 패널: 도구 막대 "자동 맞춤"(폰 보정 삭제), 범위 칩의 ×(해당 범위 삭제), 우클릭 메뉴, Ctrl+Z.
2. 설정 메뉴 "저장된 보정" 탭:
   - 폰 보정 목록(현재 세이브만, 게임 중이 아니면 "게임을 불러오면 표시됩니다"), 종족 보정 목록.
   - 한 줄에 이름 · 값 요약(`1.20× · X +0.05 · Z +0.15`) · [삭제].
   - 목록마다 "모두 삭제". 폰 목록에는 "없는 폰 정리"(파괴·소멸된 폰 항목 삭제).
   - 종족 목록은 불러오지 않은 종족도 "(불러오지 않음)"으로 보여 주고 지울 수 있게(기존 `RaceNotLoaded` 키 재사용).
   - "모든 설정 초기화"는 폰 보정까지 지울지 확인 대화를 띄운다(세이브 데이터를 건드리는 유일한 전역 동작).
3. 어떤 보정을 지워도 결과는 항상 그 아래 단계(폰 → 종족 → 전체 → 자동 맞춤)여야 한다. 숨은 값이 남지 않게 한다.

## 설정 메뉴 재구성

- 일반 탭: 켜기, 필터들, 배경·이름 표시, 실시간 초상화, 선택 해제 후 유지, 드래그 허용, **도구 막대 표시**(새 항목), 편집 모드 단축키 안내.
- 초상화 탭: 자동 맞춤 체크박스를 맨 위로. 줌·얼굴 강조·cutoff·패널 크기·위치 슬라이더는 접히는 "고급(수치 입력)" 섹션으로 이동(기본 접힘). 숫자 입력 범위 확장은 유지.
- 저장된 보정 탭: 위의 목록 화면. 기존 `DrawRaceZoomSection` 은 이 탭으로 옮기고 폰 목록을 추가.
- 번역: 새 키는 Korean 에 한국어, 나머지 23개 언어에는 영어(기존 관례). 기존 키는 바꾸지 않는다.

## 첫 실행 안내

- 업데이트 후 패널이 처음 표시될 때 패널 옆에 작은 말풍선: "패널 위에 마우스를 올리면 편집 도구가 나타납니다." 닫기 버튼. 한 번 닫으면 `HoverToolbarHintShown = true` 로 저장해 다시 보이지 않는다.
- 도구 막대를 설정에서 끄면 안내도 보이지 않는다.

## 기존 사용자 보호

- 구도 계산은 보정이 모두 항등일 때 1단계 결과와 완전히 같아야 한다(자동 맞춤이 꺼진 기존 사용자는 지금 화면 그대로).
- 설정 파일 마이그레이션: `RaceZoomOverrides` 형식이 바뀌므로 1단계 형식(float)으로 저장된 파일이 있으면 `ZoomMultiplier` 로 읽어 들인다(출시 전이라 테스트 사용자용).
- `SettingsVersion` 을 2로 올린다.

## 구현 메모

- 편집 모드의 입력 처리는 `SelectedPawnPortraitOverlayComponent` 의 `ImmediateWindow` 델리게이트 안에서 한다. `absorbInputAroundWindow: false` 는 유지하되, 편집 모드이고 마우스가 패널 위에 있을 때만 MouseDown/Drag/ScrollWheel 을 `Use()` 한다.
- 휠 이벤트는 `EventType.ScrollWheel`, `Event.current.delta.y`. RimWorld 는 맵 줌을 `Update` 에서 `Input.mouseScrollDelta` 로도 읽을 수 있으니, 편집 모드에서 패널 위에 있을 때는 한 프레임 동안 맵 줌을 막을 방법(예: `Find.CameraDriver` 의 입력을 가로채는 Harmony 없는 방법이 없으면 이 한계를 보고)이 필요한지 확인한다.
- 1.6 과 1.7 모두 빌드해야 하며(경고·오류 0), Mods 폴더 복사본에 반영한다. 빌드·배포 절차와 "게임 실행은 사용자 허락 후" 규칙은 1단계와 같다.
- 모든 새 UI 문자열은 번역 키로 둔다(하드코딩 금지).

## 완료 기준

- 패널에 마우스를 올리면 도구 막대가 나타나고, 설정에서 끌 수 있다.
- 편집 모드에서 드래그·휠·손잡이·프리셋이 동작하고, 범위 칩으로 저장 위치를 바꿀 수 있다.
- 폰별 보정이 세이브에 저장·복원된다. 종족 보정은 설정 파일에 저장된다.
- 세 경로(패널, 우클릭, 설정 탭)로 보정을 지울 수 있고, 지운 뒤의 화면이 아래 단계와 일치한다.
- 보정이 없는 상태의 구도는 1단계와 픽셀 단위로 같다(미리보기 도구로 확인).
- 첫 실행 안내가 한 번만 보인다.

## 단계 나누기

- 2a: 데이터 모델(`PortraitAdjustment`, 종족·폰 저장), 도구 막대, 편집 모드(드래그 이동, 휠 줌, 범위 칩, 자동 맞춤 버튼), 우클릭 삭제 메뉴, 설정의 저장된 보정 탭.
- 2b: 프리셋 3종, 자르기·모서리 손잡이, Ctrl+Z, 수치 읽기와 더블클릭 입력, 고급 섹션 접기, 첫 실행 안내, 단축키.
